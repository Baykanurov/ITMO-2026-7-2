# Как помочь проекту

1. **Баг** — опишите шаги воспроизведения, ожидаемое и фактическое поведение, версию Python.
2. **Идея** — что хотите и зачем это нужно.
3. **Вопрос** — сначала загляните в README, потом спрашивайте.

Pull Request: отдельная ветка, один PR — одно изменение, в описании `closes #<номер Issue>`.
